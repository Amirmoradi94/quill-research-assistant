How the AI does this in one shot

Backend spawns: claude -p "<user instruction>" --allowed-tools "Read,Edit,Bash" --cwd ~/.../cv/ --output-format stream-json
Claude calls Read on CV_Amir_Moradi.tex → reasons about which lines to change
Calls Edit with precise old/new strings (one or many calls in sequence)
Calls Bash("tectonic CV_Amir_Moradi.tex") — Tectonic is a Rust-based portable LaTeX engine, single binary, downloads packages on demand
Backend watches the file system → sees new .pdf mtime → renders via pdf.js in the left preview
Tool-call events stream into the right sidebar so the user sees each step as it happens (Cursor's "reasoning close to the work" principle)
